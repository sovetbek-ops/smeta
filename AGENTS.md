# Правила работы

- Работать только в этой папке. Перед изменениями сначала читать текущие файлы.
- Делать только ту функцию, которую просит пользователь, и не ломать уже работающие функции.
- Использовать только обычные HTML, CSS и JavaScript. Не использовать npm, фреймворки и внешние ресурсы.
- Данные пользователя должны оставаться в браузере. Ничего не отправлять в интернет.
- Делать понятные подписи. Поля и кнопки должны быть не меньше 44 × 44 px. Обеспечивать работу с клавиатуры и на телефоне.
- Показывать деньги с пробелами между тысячами, например: `15 000 ₸`. Пустые и неверные числа считать нулём. Никогда не показывать `NaN`.
- Не запускать git и ничего не публиковать без просьбы пользователя.
- После работы перечислять изменённые файлы и объяснять, как проверить результат.
