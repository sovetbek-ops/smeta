# Смета за 5 минут

Веб-приложение для быстрого составления сметы или коммерческого предложения и сохранения результата в PDF.

Приложение предназначено для предпринимателей, которые готовят КП клиентам, и офисных сотрудников, которым нужно составить смету закупки или показать расходы руководителю.

## Файлы приложения

- `index.html` — структура страницы: поля сметы, список позиций, итог и кнопки действий.
- `styles.css` — оформление страницы, размеры элементов и адаптация для телефона.
- `script.js` — работа с позициями, расчёт сумм, форматирование денег и сохранение в PDF.

Эти файлы будут созданы на следующих этапах. Сейчас в папке есть только документация проекта.

## Как открыть

После создания файлов приложения дважды щёлкните по `index.html` — он откроется в браузере. Установка программ и запуск сервера не требуются.

## Как проверить

После реализации расчёта добавьте две позиции:

1. Количество — 2, цена — 15 000 ₸. Сумма — 30 000 ₸.
2. Количество — 1, цена — 8 000 ₸. Сумма — 8 000 ₸.

Ожидаемый итог: **2 × 15 000 + 1 × 8 000 = 38 000 ₸**.
